# Notebooks

SAM 2 verification demos exported from Vast.ai instance.

## How to pull from instance

```powershell
# Replace <ip> with your Vast.ai instance address
scp -r root@<vastai-instance-ip>:/workspace/segment-anything-2/notebooks/*.ipynb notebooks/
```

## Included

- `boxes_segment.ipynb` — SAM 2 automatic mask generator batch segmentation demo
